There is an executable located in the releases tab on the right side of the project home page if the blackboard submission has issues.

Just so you know what to look out for, there are unique sound effects for button clicks, ui panels opening, ui panels closing, purchases completing, screen transitions, and 2 chimes when excavations fail and complete successfully.

There are animations for the coin in the top left, the progress bar, buttons, ui opening, and scene transitions. 

All assets used in the game are located in game/assets.

All assets were either made by someone else and free for use or, in the case of the background images, generated by my USC chat gpt account, since the versions i tried to make didn't look very good.

I also used my USC chat gpt account to generate some of the source code later on when I started to run out of time and to debug when I couldn't figure out certain issues. 
I also used it during the beginning of the project to teach me what everything in Godot does since I hadn't used it before the project.

If you want to reset your game data, on the windows file directory you can go to %appdata%/Godot/app_userdata/Museum game/ and delete museum_game_save
